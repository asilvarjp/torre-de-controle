Configuração necessária

O arquivo js/config.js ainda não foi preenchido com os dados do seu projeto Supabase.

  1. Crie um projeto gratuito em supabase.com.
  2. Rode o script supabase/schema.sql no SQL Editor do projeto.
  3. Copie a Project URL e a anon public key em Project Settings → API.
  4. Cole os dois valores em js/config.js e recarregue esta página.

Veja o passo a passo completo no README.md do repositório.
